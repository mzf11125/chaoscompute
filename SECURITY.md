# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| main branch | Yes |
| All other branches | No |

## Reporting a Vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Email the maintainer directly at mzidanfatonie@gmail.com with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes

You will receive a response within 48 hours. Once confirmed, we will:

1. Develop and test a fix
2. Release the fix as soon as possible
3. Credit you in the release notes (unless you prefer to remain anonymous)

## Scope

Security reports are accepted for:

- The ChaosCompute Gateway application
- The chaoscompute.yaml pay.sh provider spec
- The Anchor on-chain program
- The Python and Node.js SDKs
- The ChaosCompute Docker setup

Reports for npm dependency vulnerabilities are also accepted but may be lower priority if they do not affect production builds.
